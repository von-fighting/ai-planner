## v2.11 UI 修复 ⚡
航哥反馈：Landing页面"立即开始规划"按钮下面的内容（3步搞定、底部区域）背景是白的
- **根因**：`.landing-bg` 用 `height: 100%` 只覆盖首屏高度，滚动后下方内容超出视口就没有背景了
- **修复**：将 `.landing-bg` 的 `height: 100%` 改为 `min-height: 100%`，让背景层随内容自动撑开
- 同时修复了之前遗留的 CSS 语法错误（断掉的 `.logo {` 无闭合括号）
- Header 美化升级：三色渐变 + 双光晕动画 + logo加大加阴影 + padding加高
